Quick Start

Siap Digunakan dalam Detik

Konfigurasi lanjutan tersedia melalui ~/.eco/config.json.

Terminal
$ npm install -g eco-agent
$ eco-agent "buat REST API todo list"
Terminal
$ curl -fsSL https://eco-agent.dev/install.sh | bash
$ eco-agent --version
Terminal
$ docker run -it --rm -v "$(pwd):/workspace" ghcr.io/nabilekowahyudi/eco-agent:latest
Terminal
$ git clone https://github.com/NabilEkoWahyudi/eco-agent
$ cd eco-agent && pnpm install && pnpm build
